# React Learning Lab

Отдельный учебный репозиторий: повторение материалов преподавателя, вопросы,
практические задания и мой код перед созданием личного кабинета онлайн-кинотеатра.

## Начать или продолжить

1. Прочитать [PROGRESS.md](PROGRESS.md).
2. Открыть нужную тему в [topics](topics/README.md).
3. Ответить на вопрос наставника и выполнить небольшое упражнение самостоятельно.
4. После разбора сохранить результат и обновить прогресс.

Исходные материалы: `01_ReactIntro_A_Examples_74_RU.pdf` и
`02_ReactProps_Examples_78_RU.pdf`. PDF преподавателя не публикуются в этом репозитории.
Оба PDF изучены наставником. В topics сохранены маршрут повторения, вопросы и упражнения;
ответы и практику будем проходить постепенно.

## Структура

- `topics/` — темы и упражнения.
- `practice/` — место для моего кода; готовых решений пока нет.
- `PROGRESS.md` — текущая тема, результаты и следующий шаг.
- `docs/WORKFLOW.md` — порядок работы с Mac и Linux.

## Клонирование

```bash
git clone git@github.com:michael-kuptsov/React-Learning-Lab.git
cd React-Learning-Lab
```

Чтение без настройки SSH:

```bash
git clone https://github.com/michael-kuptsov/React-Learning-Lab.git
```

Подробно: [работа с двух компьютеров](docs/WORKFLOW.md).
Сейчас это учебная основа без установленного React-приложения; команды запуска добавим вместе.

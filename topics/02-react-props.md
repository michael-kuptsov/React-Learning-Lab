## Основные идеи для обсуждения

- Родитель передаёт входные данные, ребёнок читает их; имена props и регистр должны совпадать.
- Тип значения важен: строка в кавычках отличается от числа или boolean в фигурных скобках.
- Props не изменяем, включая переданные объекты. Spread создаёт поверхностную копию.
- Значение по умолчанию подставляется при undefined или отсутствии prop.
- children — вложенное содержимое, а не обязательно массив.
- map создаёт массив результатов. Тело callback в фигурных скобках требует return.
- key нужен внешнему элементу, возвращённому из map, стабилен для записи и уникален среди соседей.
  Сам React использует key; как обычный prop он не передаётся.
- Условия выбирают содержимое. Число 0 отображается, false — не отображается.
- Пустой массив и отсутствующее значение — разные случаи.

## Практика после вопросов

В `practice/02-course-cards/` самостоятельно собрать список учебных курсов:

- CourseList получает массив через props.
- CourseCard показывает название, число уроков и статус доступности.
- Один объект описывает один курс: id, title, lessonsCount, isAvailable.
- Карточки создаются через map со стабильным id.
- Пустой массив получает понятное сообщение; количество вычисляется из массива.
- Для статуса использовать условие; для общего оформления можно добавить Card с children.
- Не изменять переданные данные. Хуки и добавление через форму пока не нужны.

Разбор по этапам: одна карточка → props → несколько карточек → map → условие → пустой список.

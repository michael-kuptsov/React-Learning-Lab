# Проверка перед началом проекта

Опрос проходит в диалоге, по одному вопросу. Сначала ученик пробует сам,
при затруднении получает подсказку, после объяснения — похожую задачу для закрепления.
Ошибки в тренировке нормальны; все темы заранее освоенными не считаем.

## Что ученик должен суметь объяснить и написать

- [ ] Различить изменение переменной, обновление DOM и обновление исходного кода инструментами.
- [ ] Объяснить назначение React, JSX, компонента и props.
- [ ] Вывести данные объекта по полям и вычисляемое значение.
- [ ] Написать корректный JSX с Fragment и className.
- [ ] Передать строку, число, boolean и объект в компонент без путаницы типов.
- [ ] Разделить список и карточку, передать данные сверху вниз.
- [ ] Использовать map с return и стабильным key на правильном уровне.
- [ ] Показать статус по boolean, обработать пустой список без лишнего 0.
- [ ] Объяснить children и почему props нельзя мутировать.
- [ ] Найти типичные ошибки в JSX и props, различить ошибку и предупреждение.
- [ ] Самостоятельно выполнить обе небольшие практики и объяснить свой код.
- [ ] Сохранить работу через commit / push и продолжить после pull на другом компьютере.

После этого можно переходить к первой части личного кабинета.
useState, формы, создание / удаление и localStorage сейчас не являются условием готовности.
Пробелы в знаниях обсуждаем и повторяем, а не закрываем готовым кодом.

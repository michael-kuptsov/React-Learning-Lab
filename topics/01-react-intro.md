## Основные идеи для обсуждения

- Присваивание обычной переменной само по себе не обновляет текст DOM и не запрашивает рендер React.
- React-компонент описывает интерфейс на основе данных. Объявить или экспортировать компонент
  недостаточно, чтобы отобразить его в подключённом приложении.
- Рендер вычисляет описание интерфейса; применение изменений к DOM — отдельный этап.
- JSX позволяет использовать JavaScript-выражения. Обычный объект можно хранить в переменной,
  но для текстового вывода нужно выбрать допустимое значение, например его поле.
- Fragment группирует JSX без дополнительного элемента в DOM.
- CSS отвечает за оформление, className связывает элемент с CSS-классом.
- Значения, которые можно получить из исходных данных, лучше вычислять.

## Вопросы — выдавать по одному

### 1. Переменная и DOM

Предположим, в HTML уже есть `<p id="device-count"></p>`:

```js
let count = 2;
const element = document.querySelector("#device-count");
element.textContent = count;
count = 3;
```

Какое число увидит пользователь и почему? Ответ пока не записан.

### 2. Поиск элемента

Что вернёт querySelector, если id не найден? Что произойдёт при обращении к textContent?

### 3. Роль инструментов

Объясни своими словами задачи React, Vite, Node.js и браузера.
Нужно ли обычное присваивание переменной React отслеживать автоматически?

### 4. Компонент

Что возвращает компонент? Чем отличаются `<h1 />` и `<UserCard />`?
Покажет ли страницу одно только `export default App`?

### 5. Текст и выражение

Если `name = "Alex"`, чем отличаются `<p>name</p>` и `<p>{name}</p>`?

### 6. JSX

Какие из значений можно использовать в JSX: `user.name`, `2 + 3`, `const x = 2`?
Объясни принцип выбора.

### 7. Группировка

Как вернуть заголовок и абзац рядом? Чем Fragment отличается от div в итоговом DOM?

### 8. Поиск ошибок

По отдельности разобрать незакрытый тег, `<p>{user}</p>` для обычного объекта
и перенос строки непосредственно после return. Что именно не так в каждом случае?

### 9. Оформление

Как связаны `className="profile"` и CSS-селектор? Что меняют margin и padding?

### 10. Рендер

Означает ли новый рендер перезагрузку страницы? Гарантирует ли Virtual DOM преимущество
в скорости перед одной прямой записью в textContent?

## Практика после вопросов

Создать учебную карточку участника курса, используя вымышленные имя, город,
общее число уроков и число пройденных уроков. Остаток вычислять из двух чисел.
Использовать JSX и CSS-класс; без props, map и хуков на этом шаге.
Код написать в `practice/01-profile/` после совместной подготовки среды запуска.

Проверить: изменение исходного имени отражается в карточке, остаток пересчитывается
при новом выполнении компонента, JSX корректен, отступы читаемы.
Готового решения здесь намеренно нет.
